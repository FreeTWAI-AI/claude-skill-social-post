# P1 Learn voice

## Inputs

Use only samples the user supplied or authorized you to inspect. Collect enough varied posts to distinguish stable voice from one campaign.

## Extract

- sentence and paragraph length;
- punctuation, emoji and line-break habits;
- opening and closing patterns;
- recurring topics, evidence style and CTA preferences;
- explicit dislikes and brand boundaries;
- distinct modes such as daily observation, product update and long-form reflection.

## Write locally

Store detailed excerpts and private evidence in `style_profile.md`. Condense only operational decisions into `voice_quick.md` so P2 does not load the full archive.

Never publish private samples, names, handles, screenshots or account metrics in the public package. Fictional examples must be labeled fictional.
